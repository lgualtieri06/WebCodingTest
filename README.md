Este proyecto es para aprender paso a paso a armar una pagina web.

La idea de esta web es que sea un portal para instructores, que tenga una pantalla de presentación que muestre un feed dinamico sobre el espacio, en el cual los instructores puedan compartir información y dar a conocer su actividad.

la pantalla principal puede tener varios apartados con información links y videos que se quieran compartir públicamente.

y debe poseer la funcionalidad para que los clientes/alumnos se puedan loguear y ver información privada y relevante para ellos. aca se puede agregar un cronograma de clases y la posibilidad de que los alumnos puedan consultar cupos y anotarse..

Mi base en programación web es nula, generalmente me dedico a abap, análisis funcional e interfaces en SAP. Deséenme suerte.
